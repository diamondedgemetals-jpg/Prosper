# Prosper - Metal Dashboard

A metal dashboard application built with Android.

## Project Structure

- `android/` - Android application files
  - `app/` - Main application module
    - `build.gradle` - Android app build configuration

## Getting Started

This project is set up to build Android App Bundles (AAB) for distribution on Google Play Store.

### Prerequisites

- Android SDK
- Gradle
- Java Development Kit (JDK)

### Build

To build the app:

```bash
./gradlew build
```

To build an Android App Bundle (AAB):

```bash
./gradlew bundleRelease
```
